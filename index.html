NameQuick for Mac

AI-powered file renaming right from your Mac menu bar. A lightweight utility that makes renaming files fast, smart, and automatic. Built for PDFs, images, and more — keeping you organized without the manual work.

AI-Powered Naming

Generate meaningful names automatically using GPT or your local LLM. Handles PDFs, images, and other files with smart, context-aware suggestions.

Local & Private

Run offline with Ollama — no internet needed, no data leaves your Mac. Or bring your own OpenAI/Gemini key, stored securely in Keychain.

Batch & Automation

Rename multiple files at once. Watch folders like Desktop or Downloads for real-time auto-renaming as files appear.

Global & Customizable

Multi-language support for any workflow. Use custom templates with dynamic placeholders like {date}, {vendor}, or {filetype}.

Always Accessible

Lives quietly in your menu bar with global shortcuts. Rename from anywhere, instantly.

How It Works

1. Select Files

Drag files to NameQuick, use global shortcuts, or let folder watching detect them automatically.

2. Choose Your AI

Pick GPT, Gemini, local Ollama, or custom provider. Enter your BYOK if needed — all secure.

3. Rename Instantly

AI generates smart names. Edit if desired, apply to one or batches. Done.

4. Stay Organized

Files get consistent, meaningful names. Set templates for recurring workflows.

FAQ

Is this fully activated?

Yes. NameQuick Version 2.11.13 is pre-activated. No purchases or subscriptions needed.

Does it work offline?

Yes, with local Ollama support. All processing stays on your Mac.

What file types are supported?

PDFs, images, scans, receipts, and more. Batch handles any combination.

Is my data private?

Absolutely. BYOK keys in Keychain, local LLM option, nothing sent to third parties.

How do I install?

Download, drag to Applications. It runs from the menu bar immediately.
